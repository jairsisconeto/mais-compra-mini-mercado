# + Compras - Mini Mercado

Site institucional desenvolvido para a empresa fictícia **+ Compras (Mini Mercado)**, apresentando a empresa, seus produtos e canais de comunicação com os clientes.

## 📋 Sobre o Projeto

Plataforma institucional criada com HTML, CSS e JavaScript puro, sem uso de frameworks ou modelos prontos. O site oferece:

- **Aba Empresa**: História, missão, valores e papel na comunidade
- **Aba Produtos**: Três linhas de produtos (Mercearia, Bebidas, Higiene e Limpeza) com 4+ produtos cada
- **Aba Contato**: Formulário de contato e integração com redes sociais
- **Aba FAQ**: Perguntas frequentes sobre horários, pagamento e política de trocas
- **Logomarca exclusiva** do + Compras

## 🚀 Como Usar

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` no navegador
3. Navegue pelas abas usando o menu superior

## 📁 Estrutura do Projeto

```
projeto_pratico/
├── index.html          # Página principal
├── css/
│   └── styles.css     # Estilos originais
├── js/
│   └── main.js        # Interatividade
└── README.md          # Documentação
```

## 🛠️ Tecnologias

- HTML5
- CSS3 (variáveis, grid, flexbox)
- JavaScript (Vanilla)
- Google Fonts (Nunito, Outfit)

## 📱 Responsividade

O site é totalmente responsivo e se adapta a diferentes tamanhos de tela, incluindo dispositivos móveis.
